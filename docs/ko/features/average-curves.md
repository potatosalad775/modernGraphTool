그래프에 현재 표시되고 있는 모든 측정 데이터를 하나의 그래프로 평균화하여, 기존 그래프와 함께 표시합니다.

## 개요

그래프 도구에 자리잡은 **평균화** 버튼을 누르면, 현재 표시되고 있는 모든 측정 데이터의 평균값을 계산하여 새로운 그래프를 추가합니다.

대표적인 사용 사례는 동일 모델의 여러 측정 데이터를 결합하는 것입니다. 예를 들어, 서로 다른 장치나 동일 장치를 여러 사람이 측정한 데이터를 하나의 대표적인 응답으로 결합하여 비교할 수 있습니다. 측정 데이터를 업로드하거나 선택한 후 평균화 버튼을 누르면, 결과는 그래프의 다른 곡선과 동일하게 동작합니다.

## 평균화 작업에 포함되는 데이터

오로지 **현재 표시되고 있는 측정 데이터**만 평균화됩니다:

- **기기 측정치**만 평균화됩니다. 타겟이나 EQ 곡선은 포함되지 않습니다. 타겟과 측정치를 평균화하면 의미 없는 곡선이 생성됩니다.
- **숨겨진 곡선은 제외됩니다.** 선택 목록에서 눈 아이콘을 사용하여 측정치를 제거하지 않고 표시 목록에서 제외할 수 있습니다.
- **업로드된 측정치도 포함됩니다.** 드래그하여 업로드한 파일은 데이터베이스에서 가져온 것과 동일하게 처리되며, 이 기능이 존재하는 주요 이유입니다.
- **현재 표시되고 있는 채널만 포함됩니다.** 좌/우 채널이 동시에 선택된 경우 L과 R 평균이 각각 표시되며, 좌우 채널 평균을 선택한 경우 평균값의 평균이 표시됩니다. 각각의 채널은 각 채널 집합을 기준으로 평균화되는 셈입니다.

2개 이상의 측정 데이터가 표시될 때까지 버튼은 비활성화 상태로 유지됩니다.

## 결과값 다루기

평균화 처리를 거친 그래프는 새롭게 추가된 그래프와 동일하게 동작하므로, 업로드된 측정치에서 할 수 있는 모든 작업을 수행할 수 있습니다:

- 색상 변경, 숨기기, 또는 선택 목록에서 제거
- EQ 패널에서 EQ 소스로 사용
- 그래프 기준선으로 설정
- `.txt` 측정 파일로 다운로드
- 모든 작업을 한 번에 되돌리기

해당 그래프의 이름은 평균화에 사용된 측정치의 수를 포함하며, 예를 들어 **평균 (3개)**와 같이 표시됩니다.

:::안내[평균화 연산은 한 번만 수행됩니다]
평균화 연산은 버튼을 누른 순간 한 번만 수행됩니다. 이후 측정치를 추가, 제거 또는 숨기더라도 기존 평균화 그래프는 업데이트되지 않습니다. 새로운 평균화 그래프를 만들려면 다시 평균화 버튼을 눌러야 합니다. 이름에 표시된 숫자는 기존 그래프가 몇 개의 곡선으로부터 만들어졌는지를 알려줍니다.
:::

:::주의[평균 그래프는 공유 링크에 저장되지 않습니다]
업로드된 측정치와 마찬가지로, 평균화 그래프는 브라우저 세션 안에서만 존재합니다. `?share=` 링크에 평균화 그래프의 정보가 포함되지 않으며, 페이지를 새로고침하면 사라집니다.
:::
