### v1.0.1

- Fixed an issue where the suffix was not displayed on phones with a single file.
- Fixed an issue where the y-offset was not reset upon a normalization change.
- Fixed an issue where the pref.bound disappeared upon a normalization change.
- Fixed an issue where the pref.bound y-scale value was not updating.
- Fixed an issue where hidden graph elements were occasionally shown.
- The channel manipulation logic has been improved.
- Removed experimental unused event handler.
