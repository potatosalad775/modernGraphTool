측정 데이터베이스를 둘러보는 모든 분을 위한 인터페이스 안내서입니다. 두 부분으로 나뉩니다.

- **기초** — 주파수 응답 그래프를 처음부터 설명하는 짧은 네 페이지입니다. 이런 그래프를 처음 본다면 여기서 시작하세요.
- **도구 사용법** — 화면의 모든 패널과 컨트롤을, 실제로 만나게 될 순서대로 다룹니다.
